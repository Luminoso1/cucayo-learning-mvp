# Cucayo Learning

An innovative web platform designed to transform the educational experience through **Micro-learning**, **Gamification**, and **Generative AI** acting as a Socratic tutor.

---

## Project Vision

This system moves away from traditional, long-form digital education. Instead, it focuses on high-retention, short-burst content that adapts dynamically to the learner's pace. The core philosophy is to guide students toward discovery rather than simply providing answers.

## Core

- **Adaptive Learning:** Real-time adjustment of the learning path. If a student progresses quickly, the difficulty increases; if they get stuck, the system automatically changes the pedagogical strategy.
- **Micro-learning:** "Atomic" content delivery (3-5 min sessions). Instead of 2-hour lectures, the system uses short videos (max 20s), images, equations, and quick challenges to maintain focus.
- **Gamification:** Implementation of game mechanics (points, levels, badges) to transform studying into a motivating and engaging experience.
- **Socratic AI Tutor (GenAI):** The heart of the project. Using models like **GPT, Gemini, or DeepSeek**, the AI doesn't give answers. It asks the right questions to guide the student to deduce the solution by themselves.

## Tech Stack

Built with a modern, type-safe, and high-performance stack:

- **Framework:** [TanStack Start](https://tanstack.com/start) (React)
- **Frontend:** [React](https://react.dev/) & [Tailwind CSS](https://tailwindcss.com/)
- **Backend & Auth:** [Supabase](https://supabase.com/)
- **ORM:** [Drizzle ORM](https://orm.drizzle.team/)
